# AI Attendance System

An automated face recognition attendance tracking system built with Python, OpenCV, and Tkinter/Flask.

## Features
* Real-time face recognition via webcam feed.
* Automated attendance logging into Excel/CSV files with timestamps.
* Dashboard for tracking attendance logs.
* Model training pipeline for adding custom face datasets.

## Tech Stack
* Python
* OpenCV
* Pandas
* Tkinter / Flask

## Usage
1. Run `dataset_creator.py` to capture training images.
2. Run `train_model.py` to train the recognition model.
3. Run `attendance_system.py` to launch the automated tracking system.
